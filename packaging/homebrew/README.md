# henriksvendsgard/homebrew-tap

Homebrew tap for [Deck](https://github.com/henriksvendsgard/deck), a Cmd+Tab window switcher for macOS.

```bash
brew install --cask henriksvendsgard/tap/deck
```

Upgrade with `brew upgrade --cask deck`.

The cask is generated from [`packaging/homebrew/deck.rb`](https://github.com/henriksvendsgard/deck/blob/main/packaging/homebrew/deck.rb) in the Deck repo by its release script. Edit it there, not here.
